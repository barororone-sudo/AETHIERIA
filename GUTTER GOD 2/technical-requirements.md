# Technical Requirements

Le jeu sera développé avec le framework WebGPU pour profiter des capacités de calcul parallèle de votre processeur. Les bibliothèques de compression de données seront utilisées pour réduire la taille des assets et améliorer le chargement du jeu.

## Frameworks et bibliothèques

* WebGPU
* Bibliothèques de compression de données

## Exigences système

* Processeur : 12th Gen Intel(R) Core(TM) i7-1255U (1.70 GHz)
* Mémoire RAM : 16,0 Go (15,7 Go utilisable)
* Système d'exploitation : 64 bits, processeur x64
